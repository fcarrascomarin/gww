# Asignación de imágenes — GWW Chile V4

Todas las imágenes del prototipo se guardan en la carpeta `assets/`.

## Imágenes ya incorporadas en este ZIP

| Nombre de archivo | Dónde se usa | Recomendación |
|---|---|---|
| `hero-rio-comunidad.jpg` | Hero principal | Imagen horizontal amplia, idealmente 1800 px o más de ancho. |
| `monitoreo-fisicoquimico.png` | Tarjeta hero “Monitoreo fisicoquímico” | Imagen vertical o recortable. |
| `monitoreo-bacteriologico.png` | Tarjeta hero “Monitoreo bacteriológico” | Imagen horizontal o cuadrada. |
| `monitoreo-macroinvertebrados.png` | Tarjeta hero “Macroinvertebrados” | Imagen cuadrada o vertical. |
| `mapa-junquillar-referencia.png` | Segunda sección / mapa de referencia | Puede reemplazarse por otra cartografía similar. |
| `logo-manzana-verde.png` | Sección de alianzas | Logo con fondo transparente o limpio. |
| `logo-gww-chile.png` | Encabezado, hero y footer | Logo principal del programa. |

## Dónde reemplazar imágenes

1. Entra a `assets/`.
2. Si quieres reemplazar una imagen, usa **exactamente el mismo nombre de archivo**.
3. Sobrescribe el archivo anterior y vuelve a publicar el repositorio.

## Si quieres agregar nuevas imágenes futuras

Usa esta convención de nombres:

- `video-2024-portada.jpg`
- `video-2025-portada.jpg`
- `cuerpo-agua-rio-penco.jpg`
- `cuerpo-agua-laguna-senoraza.jpg`
- `galeria-monitoreo-01.jpg`
- `galeria-monitoreo-02.jpg`

## Archivos clave que usan estas imágenes

- `index.html` → estructura y ubicación de cada imagen.
- `styles.css` → tamaños, bordes y comportamiento responsive.
