# Mapa del agua · V15

El mapa utiliza Leaflet/OpenStreetMap y toma los datos de `data/cuerpos-agua-publicos.geojson`.

**14 referencias geográficas documentales**, de las cuales 10 tienen un punto general y 4 aún no están ubicadas. Estas referencias NO son estaciones certificadas ni prueban monitoreo; sus datos científicos y permisos permanecen sin acreditar. El listado comunal contiene 34 equipos, NO 34 estaciones de muestreo. No se publican nombres de agrupaciones ni voluntarios.

Para agregar nuevas referencias, sigue `docs/AGREGAR_CUERPOS_DE_AGUA_V15.md` y revisa los permisos editoriales antes de subir cambios a GitHub. El catálogo es una capa preliminar para revisión institucional; cuando se desarrolle la plataforma interna, la publicación deberá provenir de un proceso controlado de validación y autorización.
