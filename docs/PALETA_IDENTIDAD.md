# Paleta oficial para GWW Chile

Se tomó de «Paleta de colores Web GWW.pdf» proporcionado por Fundación Manzana Verde.

| Color | Hexadecimal | Uso sugerido |
|---|---|---|
| Azul claro | `#68A5DD` | Fondos secundarios, ondas y pequeños detalles |
| Azul principal | `#2484BF` | Marca, títulos destacados y elementos interactivos |
| Naranja | `#DB5720` | Líneas de énfasis y detalles; no usar de forma excesiva |
| Crema | `#F2EBD5` | Fondos suaves |
| Verde | `#66824F` | Acentos territoriales y ambientales |

Para accesibilidad se emplea además un **azul oscuro derivado** (`#195C85`) en botones y fondos con texto blanco, pues el azul claro oficial no ofrece suficiente contraste para textos pequeños.

Los colores se cambian en el bloque `:root` al comienzo de `styles.css`. La identidad gráfica definitiva y las aplicaciones del logotipo oficial aún deben validarse con GWW Chile.
