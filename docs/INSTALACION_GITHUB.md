# Instalación de V15 en GitHub Pages

1. Haz respaldo del sitio anterior desde GitHub Desktop o descargando el ZIP del repositorio.
2. Descomprime el paquete V15 en una carpeta temporal.
3. Copia todos sus archivos y carpetas en la **raíz** del clon local `fcarrascomarin/gww` (junto a `.git`, que debes conservar).
4. Retira los archivos heredados listados en `docs/DEPURACION_REPOSITORIO_V15.md`, sobre todo `data/public-showcase.json`.
5. Confirma en GitHub Desktop (`Commit to main` y `Push origin`).
6. Abre `https://fcarrascomarin.github.io/gww/`. La versión correcta debe indicar «Web externa V15» en el pie.
7. En «Mapa del agua», comprueba el contador de **14 referencias documentales · 10 en mapa · 4 por ubicar**. Selecciona una referencia en el índice para abrir su ficha.
8. Para agregar cuerpos de agua consulta `docs/AGREGAR_CUERPOS_DE_AGUA_V15.md`.
